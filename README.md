# ChessHint
Оверлей с подсказкой лучшего хода (Stockfish) поверх приложения Chess.com.

## Сборка APK (без Android Studio)
1. Создай пустой репозиторий на GitHub, залей туда содержимое этой папки.
2. Вкладка Actions → build-apk → дождись зелёной галочки (~5 мин).
3. Внизу страницы запуска скачай артефакт ChessHint-apk → внутри app-debug.apk.

## Сборка в Android Studio
Скачай Stockfish (stockfish-android-armv8 с github.com/official-stockfish/Stockfish/releases),
положи как app/src/main/jniLibs/arm64-v8a/libstockfish.so, затем Build → Build APK.

## Использование
Запусти → дай разрешения → открой Chess.com, начни партию → на стартовой позиции нажми 📚 (один раз, шаблоны сохраняются).
Дальше всё автоматически: на твоём ходу стрелка с лучшим ходом (конь — буквой «Г»), над доской полоса оценки,
после каждого хода — его оценка (Блестящий !!, Сильный !, Лучший ★, Отличный/Хороший ✓, Неточность ?!, Ошибка ?, Грубая ошибка ??).
Панель: ♟ свернуть · ⏸ пауза · 📚 запомнить фигуры · ⇅ перевернуть вручную · ✕ выход. Ориентация и чей ход определяются сами.
Тема доски — стандартная зелёная.
